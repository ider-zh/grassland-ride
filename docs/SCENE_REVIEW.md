# 场景走查：钟楼到高原湖

使用原骑行视角，在白昼按顺序检查。可离线打开生成的 HTML，带 `?inspect&manual`，在浏览器控制台运行 `rideInspect.jump(里程, 11)` 复现机位。里程是路线坐标，不等于地表累积骑行距离。

| 路段 | 机位（m） | 验收线索 |
| --- | --- | --- |
| 驿镇 | 4 / 76 / 149 | 钟楼与门楼可辨、窄街打开到市集和旅店、再离开镇子 |
| 去程草原 | 2097 / 2200 | 草带与避风树群构成近中景，山体从远景变成峡谷入口 |
| 峡谷 | 2440 / 2463 / 2480 | 接近、穿越、离开裂岩门，道路与骑手不被地形穿面 |
| 山脊 | 3180 / 3204 / 3270 | 护栏外读得出坡面高差，远侧山脊与近处层岩不混成一面墙 |
| 高原 | 4214 / 4290 / 4360 | 石台和路标先出现，随后沿路露出湖面和岸线 |
| 回程 | 5260 / 6848 / 6900 | 金草坡区别于去程，临近起点可认出同一座钟楼 |

近、远地形使用相同的横向采样和边界顶点。每个区块同时只显示一个精度，避免远处粗网格插进近处道路。湖盆和山脊落差是球面地形的一部分；装饰物和摄像机构图不改变可骑行区域。玩家手动拖拽镜头后，自动取景让位于手动视角。

`node tests/route.test.mjs` 检查环线接缝、坡度及湖面不穿骑行道。走查和程序测试不应代替真机性能测试。
